# Scientific Glossary

| Term | Definition |
|---|---|
| DSR | Deflated Sharpe Ratio accounting for selection and non-normality. |
| CSCV-PBO | Combinatorially symmetric cross-validation estimate of backtest overfitting probability. |
| White Reality Check | Bootstrap test of whether the best strategy beats the benchmark after selection. |
| Hansen SPA | Superior Predictive Ability test with studentization. |
| Aligned family | Strategies observed on the same time axis and eligible for joint inference. |
| Frozen release | Immutable, checksum-bound result package. |
| Paper snapshot | Dated manuscript pinned to one admitted evidence state. |
