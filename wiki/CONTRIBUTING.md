# Contributing to the Research Wiki

One fact has one owner: wording in `claims/`, values in `evidence/` and
`results/`, inputs in `datasets/`, lifecycle in `status/`, decisions in
`decisions/`, and exports in `manuscript/`. Every page carries front matter.
A scientific number requires an evidence ID before claim review. Numerical
changes create a new frozen release under `docs/RESULT_FREEZING.md`; negative
and inconclusive outcomes remain visible.
