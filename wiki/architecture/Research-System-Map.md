# Research System Map

```text
free market sources -> prepared aligned returns + manifest
    -> sixteen strategy audits -> seven-gate accounting/execution checks
    -> multiple-testing statistics -> frozen evidence
    -> evidence ledger -> scoped claims -> paper snapshot
```

Only synchronized strategy returns enter joint CSCV/RC/SPA inference. Case
studies on other assets or frequencies remain separate evidence families.
