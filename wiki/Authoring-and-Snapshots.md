# Authoring and snapshots

The full Markdown manuscript in `paper/current_state/` is authoritative for the
current narrative. `paper/conference_snapshot/` is a historical submission
state. `results/frozen/<release-id>/` is immutable numerical evidence.

Documentation may clarify interpretation without changing the evidence release.
Any numerical correction must follow `docs/RESULT_FREEZING.md`, receive a new
release identifier, and update the evidence ledger and manuscript together.
