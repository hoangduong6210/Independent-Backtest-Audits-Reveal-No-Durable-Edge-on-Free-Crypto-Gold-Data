# Paper states

`current_state/` is the public full manuscript used by the README and wiki.
Its Markdown source is authoritative; the adjacent PDF is a rendered snapshot.
Figures are versioned in `figures/generated/`.

`conference_snapshot/` preserves the ICAIF-oriented manuscript state and source.
It is historical and must not be used as the source for current claims without
checking the evidence map.

Earlier Word, PDF, and exploratory paper artifacts remain available locally in
`archive/legacy-source/` but are not part of the public Git release.
